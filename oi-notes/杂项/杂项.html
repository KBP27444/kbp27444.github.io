杂项 ​

怎么对着样例调试？ ​

输出中间信息，和手算比较一下是否相同，如果不同就具体调试。

比如线段树，可以写一个 write 函数递归输出每个节点信息。

对拍 ​

为什么我样例过了，交上去就 0 分了？

我们需要测试代码在更多的数据下是否还能正确。

造一个机器，自动随机生成数据，然后看我的代码和暴力代码是否相同。

写暴力 ​

我要写怎样的暴力？

越简单越好！比如线段树相关，直接写 $O(Qn),O(n^2)$ 暴力。不容易写错而且效率也不错。

生成随机数据 ​

cpp
std::mt19937 rnd(random_device{}());

a=rnd()%M;

这样的随机数较强。

比如我们要生成线段树题的数据，那么就随机一个序列，然后随机区间和操作。

cpp
l=rnd()%n,r=rnd()%n;
if(l>r)swap(l,r)

怎么随机一棵树？ ​

  • 我每次随机一条边，然后并查集维护一下把他加进去（太垃圾）。

  • 随机一个 prufer 序列，然后生成（太难写）。

对于每个 $i>1$ ，将 $i$ 连向 $[1,i-1]$ 中一个随机的点。

怎么随机一个图？ ​

先生成一棵树，然后在上面随便加 $m-(n-1)$ 条边。

怎么自动化对拍？（linux），windows 需要自行修改。 ​

cpp
system("g++ bl.cpp -o bl -O2");
system("g++ a.cpp -o a -O2");
system("g++ mkdt.cpp -o mkdt -O2");
int T = 0;
while (1) {
    system("./mkdt");
    system("./a");
    system("./bl");
    if (system("diff 1.out 1.ans -b")) {
        cout << "WA";
        return 0;
    }
    cout << "AC" << ' ' << (++T) << endl;
}

对拍通过，就能下一个保险，如果对拍没过，也可以轻松获得小规模的数据来帮助调试。

所以在写正解前快速写个暴力是很好的策略。

一定不要懒得写对拍丢掉不该丢的分。

AI 使用指南 ​

我只会用豆包，我觉得他太垃圾了怎么办？

主流 AI 有哪些？ ​

国外御三家：claude, gpt, gemini.

国内主流：豆包，deepseek.

豆包最区，干活能力很差。

deepseek 数学推理、代码能力都不错，但是综合能力稍逊国外 AI。

gemini 是有免费网页版的（如果你会科学上网），用起来最方便。但是阉割比较严重，常被称为美国豆包。

gpt，claude 是最顶级的 AI，但是价格很贵，而且使用门槛比较高。

怎么用？ ​

豆包和 deepseek 的网页版用起来很简单，但是能力很受限。

现在 AI 的能力非常强，你在学习和生活中遇到任何问题，都可以想办法让 AI 来介入解决。

举例：woc，这个题完全不会做，题解又写得依托，我该怎么办呢？

AI 的编程能力很强，很多模型都能轻松达到 cf 2400+ 的水平，指导大家完全足够，但是网页版肯定用不出这样的能力。

获取一个 api ​

deepseek 官网，点 api 开放平台。

创建一个「api key」，然后充点钱，一般来说平常用用一天一块钱都不到。（会根据输出的 token 计费）。

为什么要用 api？因为 api 是没有阉割的完全形态，能力很强。

api 怎么用？ ​

最简单：我想要搭建一个本地的 chat ，怎么用？

不懂的都可以用 AI 解决，因为我也是问 AI 才知道怎么配的。

我的方法是下载一个 chatbox，开箱即用。

可以设置一个 prompt，作为对话的设定，这样整个对话全部都基于这个设定来回答。

搭建一个 code agent！ ​

chat 会出现一些问题？

  • woc这个 AI 根本没看懂我的题目，写出来的代码完全不对。

  • 我让这个 AI 调代码，它怎么完全调不出来？

  • 怎么使用 vscode 啊，我出现了各种问题（配环境）。

  • 电脑其他相关问题（我电脑为啥这么卡，有没有什么办法加快一下运行速度）。

我们需要 AI 来看到我们的电脑里的文件再工作

下载一个 claude，或者 codex。（如果不会下载，可以 chat 问 AI）。

然后跟着配置，我们就得到了一个 code agent，他可以看到我们电脑上的文件。

一个简单的测试：看一下我的电脑，有没有什么垃圾文件可以清理。

发现它确实能看到我整个电脑的所有文件。

然后上面的问题就很简单了，你直接把问题给 AI，他就能解决。

skills：从解决问题到干活 ​

我们现在学会了怎么让 AI 解决我们问出的问题了，但是如果想要 AI 来帮助我们学习，我们要让他实现一些综合的功能体。

比如说，我们遇到一个洛谷题目，不会做，但是题解写得依托我完全看不懂，怎么办。我想要一个人用生动的语言来教我这个题怎么做。

我们可以让 AI 来帮助我们做这个过程，我们可以把这个过程变成 skill.md ，然后 AI 就会根据我的过程来执行。

可以认为，我们可以把一个用很多次的问题存成一个 md 文件，每次快速调用。

举个例子，上面的就需要这样几步：

  • 把洛谷题目、题解、最好还要有代码爬下来。

  • 让 AI 理解一下这题怎么做。

  • 用我能接受的语言来教我怎么做。

把这个流程交给 AI ，让 AI 写个 skill.md ，我们就可以用 AI 辅助了！

总结 ​

到这里，你已经是超过 90% 以上大一学生的 agent 工程师了！

agent 可能还有一些不足，比如上面的题解依然不尽人意，需要更多的研究来变得更好。但至少这是一个好的开始。

现在是 AI 的时代，我们更需要的是提出问题，提出你的需求，然后用 AI 来解决。
