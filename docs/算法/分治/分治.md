# 一个简单的序列分治思路

给出一个序列，想要求出每个区间的 $\min$ 的和，怎么做？

可以单调栈，但是更简单的是考虑进行一个中间的分界点，然后考虑跨越这个分界点的所有区间的答案。

那么就是左右两部分取 $\min$ 的和，就是一个简单的技术了。

---

```cpp
long long divide_and_conquer(vector<int> &a, int l, int r) {
    if (l==r) {
        return a[l];
    }
    int mid=(l+r)>>1;
    long long res = 0;
    res += divide_and_conquer(a, l, mid);
    res += divide_and_conquer(a, mid+1, r);
    for (int mn=1e9, i=mid, j=mid+1; i>=l; i--) {
        mn = min(mn, a[i]);
        while (a[j]>=mn && j<=r) j++;
        res += 1ll * (j - mid - 1) * mn;
    }
    for (int mn=1e9, i=mid, j=mid+1; j<=r; j++) {
        mn = min(mn, a[j]);
        while (a[i] > mn && i >= l) i--;
        res += 1ll * (mid - i) * mn;
    }
    return res;
}
```

## 两种分治算法全景图

| 特性 | CDQ 分治 | 整体二分 |
|------|:-----:|:-----:|
| **全称** | 陈丹琦分治 | Parallel Binary Search |
| **核心** | 跨区间贡献 | 多个二分一起做 |
| **解决问题** | 多维偏序、DP 优化 | 多询问的整体二分答案 |
| **数据结构** | 树状数组 | 树状数组 |
| **典型复杂度** | $O(n \log^2 n)$ | $O(n \log^2 n)$ |
| **离线/在线** | 离线 | 离线 |
| **代表题目** | 陌上花开 | 区间第 k 小 |

> 两者都是**离线分治**框架，核心思想是将多个问题一起分治处理。

## 回忆：普通分治 vs 进阶分治

```
普通分治（归并排序）：          CDQ 分治：
  [l, mid] 独立排序              [l, mid] 内部处理
  [mid+1, r] 独立排序           [mid+1, r] 内部处理
  合并两个有序段                 处理跨 mid 的贡献 ← 关键！
                                （排序 + 树状数组）

普通分治：子问题独立，合并简单。
CDQ 分治：子问题独立 → 但需额外处理"左侧对右侧影响"。
整体二分：所有询问一起二分 → 按 mid 划分。
```

## 一、CDQ 分治

---

## 什么是 CDQ 分治？

由 IOI 2008 金牌得主**陈丹琦**在高中时整理总结并命名。

**核心思想**：将所有点对 $(i,j)$ 分为三类：
1. $i, j$ 都在左半 → 递归
2. $i, j$ 都在右半 → 递归
3. **$i$ 在左、$j$ 在右** → 这是 CDQ 分治需要**额外处理**的部分！

> 第三类恰好**跨越中点**，此时"左在右前"的天然偏序关系可以用来降维。

```
   [ i₁  i₂  i₃ | j₁  j₂  j₃ ]
       ↑ 左半       ↑ 右半
   "左半 a ≤ 右半 a" 天然成立 → 降掉第一维！
```

---

## CDQ 分治处理三维偏序

> **三维偏序**：统计满足 $a_j \le a_i,\ b_j \le b_i,\ c_j \le c_i$ 的点对数。

**核心套路：一维排序，二维归并，三维树状数组。**

```
Step 1: 按 a 排序 → 消去第一维
  排序后：左边元素的 a ≤ 右边元素的 a（天然成立）

Step 2: CDQ 分治
  - 左右分别递归，按 b 排序
  - 双指针扫描：i(左) j(右)
    b[i] ≤ b[j] → 将 c[i] 加入树状数组，i++
    b[i] > b[j] → 查询树状数组中 ≤ c[j] 的个数，加入答案，j++

Step 3: 清空树状数组（用减回的方式，避免 memset）
```

> 三维 → 排序消一维 → CDQ 消一维 → 树状数组消一维 = $O(n \log^2 n)$

---

## 三维偏序：模板代码

```cpp
void CDQ(int l, int r) {
    if (l == r) return;
    int mid = (l + r) >> 1;
    CDQ(l, mid); CDQ(mid + 1, r);

    // 左右分别按 b 排序
    sort(a + l, a + mid + 1, cmpB);
    sort(a + mid + 1, a + r + 1, cmpB);

    int i = l, j = mid + 1;
    while (j <= r) {
        while (i <= mid && a[i].b <= a[j].b) {
            BIT.add(a[i].c, a[i].cnt);   // 左半元素插入树状数组
            i++;
        }
        a[j].ans += BIT.query(a[j].c);   // 右半元素查询前缀和
        j++;
    }
    // ★ 清空树状数组（回滚）
    for (int k = l; k < i; k++)
        BIT.add(a[k].c, -a[k].cnt);
}
```

**关键细节**：
- 重复元素先去重，记录 `cnt`（出现次数）
- 插入和查询都用 `cnt` 而非 1
- 最终答案 = `ans + cnt - 1`（自身内部贡献）

---

## 为什么跨区间处理能降维？

分治到某一层时，`[l, mid]` 和 `[mid+1, r]` 天然保证了左半区间的第一维都 ≤ 右半区间（因为 Step 1 的全局排序）。

此时在**该层内部**处理跨区间点对时：
- 第一维关系已天然满足 → 无需再考虑
- 只需按第二维 `b` 双指针 + 第三维 `c` 树状数组

```
原问题: 三维偏序 (a, b, c)
  ↓ 按 a 排序
当层: 左边a ≤ 右边a → 只需处理 (b, c) 的二维偏序
  ↓ CDQ 分治（每层 O(n log k)）
O(n log² n)
```

---

## 高维偏序的推广

| 维数 | 做法 | 复杂度 |
|:--:|------|:--:|
| 二维 | 排序 + 树状数组 | $O(n \log n)$ |
| 三维 | 排序 + CDQ + 树状数组 | $O(n \log^2 n)$ |
| 四维 | 排序 + CDQ + CDQ + 树状数组 | $O(n \log^3 n)$ |
| k 维 | 排序 + (k-2) 层 CDQ + 树状数组 | $O(n \log^{k-1} n)$ |

**CDQ 套 CDQ**：不用树状数组，用第二层 CDQ 代替。
- 第一层：标记元素是 LEFT/RIGHT
- 第二层：只处理 LEFT→RIGHT 的贡献
- 扩展性更强，可以嵌套到任意维

## CDQ 分治优化 DP

**适用问题**：形如 $dp_i = 1 + \max\limits_{j < i, a_j < a_i, b_j < b_i} dp_j$ 的转移。

**关键区别**：跨区间处理必须放在两次递归**中间**（中序遍历）：

```cpp
void solve(int l, int r) {
    if (l == r) return;
    int mid = (l + r) >> 1;
    solve(l, mid);                    // 1. 先处理左半
    // ===== 处理跨区间转移 =====       // 2. 中间！左更新右
    sort(l, mid, byB); sort(mid+1, r, byB);
    // ...双指针 + 树状数组...
    solve(mid + 1, r);                // 3. 再处理右半
}
```

> ⚠️ 不能先处理跨区间再递归。必须保证"左已算完 → 左更新右 → 右开始计算"的时序。

---

## CDQ 分治：动态问题转静态

**核心思想**：将时间轴上的修改和询问用 CDQ 分治处理。

将时间 $t$ 视为新的一维：
- 修改 = 在 $t$ 时刻赋值
- 询问 = 查询 $t$ 时刻的状态
- CDQ 保证了左侧修改必然在右侧询问之前完成

```
序列: [ 修改₁  修改₂ | 询问₁  询问₂ ]
       ← 左侧修改    → 对右侧询问生效
       "修改独立时可分治，修改不独立时夹在递归中间"
```

**经典应用**：
- CQOI 2011 动态逆序对
- Ynoi 2016 镜中的昆虫（区间赋值，数颜色）
- HNOI 2010 城市建设（动态 MST）

## 二、整体二分
### Parallel Binary Search

---

## 什么是整体二分？

**普通二分**：对每个询问单独二分答案。
**整体二分**：把所有询问**放在一起**二分！

```
普通二分：                  整体二分：
Q1: 二分[1,100] → 二分...      所有 Q 一起：
Q2: 二分[1,100] → 二分...      mid=50, 对每个Q判断是≤50还是>50
Q3: 二分[1,100] → 二分...      分成两组，递归处理
...                          一次划分处理所有询问！
每个询问独立二分                多个询问共用信息
```

**核心问题**：给定多个"区间第 k 小"询问，一次解决所有查询。

---

## 整体二分算法框架

```cpp
void solve(int l, int r, int ql, int qr) {
    // l,r: 答案值域;  ql,qr: 当前处理的询问和操作区间
    if (ql > qr) return;
    if (l == r) {
        for (int i = ql; i <= qr; i++)
            if (q[i].type == QUERY) ans[q[i].id] = l;
        return;
    }
    int mid = (l + r) >> 1;
    // 处理：统计每个询问 ≤ mid 的贡献
    // 将 ql..qr 分成 q1 (≤ mid) 和 q2 (> mid)
    // 递归！
    solve(l, mid, ql, ql + cnt1 - 1);
    solve(mid + 1, r, ql + cnt1, qr);
}
```

**适用范围**（许昊然论文）：
1. 答案可二分 ✓
2. 修改贡献互相独立 ✓
3. 贡献满足交换律、结合律、可加性 ✓
4. 允许离线 ✓

---

## 静态区间第 k 小

```cpp
struct Query { int l, r, k, id, type; };
// type=1: 数值插入;  type=2: 区间询问

void solve(int l, int r, int ql, int qr) {
    if (ql > qr) return;
    if (l == r) {
        for (int i = ql; i <= qr; i++)
            if (q[i].type == 2) ans[q[i].id] = l;
        return;
    }
    int mid = (l + r) >> 1, cnt1 = 0, cnt2 = 0;
    for (int i = ql; i <= qr; i++) {
        if (q[i].type == 1) {  // 插入数值
            if (q[i].l <= mid)       // 值 ≤ mid → 加入树状数组
                { BIT.add(q[i].id, 1); q1[++cnt1] = q[i]; }
            else
                q2[++cnt2] = q[i];
        } else {                // 询问
            int t = BIT.sum(q[i].r) - BIT.sum(q[i].l - 1);
            if (q[i].k <= t)          // 答案在 ≤mid 中
                q1[++cnt1] = q[i];
            else                      // 答案在 >mid 中
                { q[i].k -= t; q2[++cnt2] = q[i]; }
        }
    }
    for (int i = 1; i <= cnt1; i++) // 回滚树状数组
        if (q1[i].type == 1) BIT.add(q1[i].id, -1);
    // 合并回原数组 + 递归
    // ... copy q1,q2 back to q ...
    solve(l, mid, ql, ql + cnt1 - 1);
    solve(mid + 1, r, ql + cnt1, qr);
}
```

> 复杂度：$O((n+q) \log V \log n)$

## 带修改区间第 k 小

**核心**：把修改拆成两个操作——**删除旧值 + 插入新值**。

```cpp
struct Opt { int x, y, k, type, id; };
// type=0: 修改 (x=位置, y=值, k=+1插入/-1擦除)
// type=1: 询问 (x..y=区间, k=第k小)

void solve(int l, int r, int L, int R) {
    // ...同框架...
    for (int i = L; i <= R; i++) {
        if (q[i].type == 0) {  // 修改操作
            if (q[i].y <= mid)
                BIT.add(q[i].x, q[i].k), q1[++cnt1] = q[i];
            else
                q2[++cnt2] = q[i];
        } else {               // 询问操作
            int t = BIT.query(q[i].y) - BIT.query(q[i].x - 1);
            if (q[i].k <= t) q1[++cnt1] = q[i];
            else q[i].k -= t, q2[++cnt2] = q[i];
        }
    }
    // 回滚 + 递归...
}
```

> 所有操作统一按时间顺序排列，分治时保持相对顺序不变。

## 整体二分优化：指针追踪法

对于静态区间第 k 小，可以维护一个指针 `pos` 追踪当前值域的边界：

```cpp
while (pos <= n && a[pos + 1].first <= mid)
    BIT.add(a[pos + 1].second, 1), pos++;  // 加入 ≤mid 的数
while (pos >= 1 && a[pos].first > mid)
    BIT.add(a[pos].second, -1), pos--;      // 移除 >mid 的数
```

**优势**：
- 不需要在每个询问中反复操作树状数组
- 每层只需要 $O(n)$ 次 BIT 操作而非 $O(n \log n)$ 次
- 可以将静态问题优化到 $O(n \log n)$

> ⚠️ 指针法下**不修改询问中的 $k$ 值**，通过 BIT 查询的结果直接划分

## 整体二分 vs 可持久化线段树

| 特性 | 整体二分 | 主席树 |
|------|:-----:|:-----:|
| 离线/在线 | 离线 | 在线 |
| 静态第 k 小 | $O(n \log n)$ | $O(n \log n)$ |
| 带修第 k 小 | $O(n \log^2 n)$ | 树套树 $O(n \log^2 n)$ |
| 空间复杂度 | $O(n)$ | $O(n \log n)$ |
| 代码量 | 中等 | 中等 |
| 扩展性 | 支持复杂条件 | 经典做法 |

> 整体二分不需要可持久化，空间更优；但必须离线。

## 三、总结与对比

---

## CDQ 分治 vs 整体二分

| 维度 | CDQ 分治 | 整体二分 |
|------|:-----:|:-----:|
| **分治维度** | 下标（序列位置） | 值域（答案范围） |
| **核心套路** | 处理跨 mid 的点对 | 按 mid 划分询问 |
| **数据结构** | 树状数组维护第三维 | 树状数组维护 ≤mid 的数 |
| **经典问题** | 三维偏序 | 区间第 k 小 |
| **时间复杂度** | $O(n \log^2 n)$ | $O(n \log^2 n)$ |
| **关键区别** | 先排序消第一维 | 直接对答案值域分治 |

---

## 两者可以结合使用

有些问题**先 CDQ 求排名，再整体二分求答案**：

例如"区间前驱后继"问题：
1. 用 CDQ 分治离线求出区间排名
2. 用整体二分求出前驱/后继

> 两者并非互斥——可以串行组合，一个为另一个预处理。

---

## 核心要点回顾

**CDQ 分治**：
1. 处理**跨中点**的贡献是核心——利用"左在右前"消去一维偏序
2. **一维排序，二维归并，三维树状数组**——三维偏序的标准解法
3. CDQ 套 CDQ 可推广到任意维偏序
4. 优化 DP 时跨区间处理**必须夹在两次递归之间**（中序遍历）

**整体二分**：
1. 将所有询问**一起二分**——共用信息减少重复计算
2. 每层用**树状数组**判定每个询问答案 ≤ mid 还是 > mid
3. 带修版本将修改**拆为删除+插入**两个操作
4. 指针追踪法可将静态问题优化到 $O(n \log n)$
