链表：用指针连接元素 65 / 132 数组和 vector 依靠连续下标找元素。 链表依靠“下一个是谁”找元素。 每个节点通常包含： • 当前值。 • 指向下一个节点的位置。 • 双向链表还会记录上一个节点。 链表更重视相邻关系，而不是第几个元素。 普及数据结构 栈、队列、链表、向量

链表的优势与代价 66 / 132 优势： • 已知位置后，插入删除附近节点很快。 • 不需要整体移动后面的元素。 • 适合维护动态相邻关系。 代价： • 不能 𝑂 ( 1 ) 访问第 i 个元素。 • 查找某个位置可能要一路走过去。 • 指针写错容易断链。 普及数据结构 栈、队列、链表、向量
