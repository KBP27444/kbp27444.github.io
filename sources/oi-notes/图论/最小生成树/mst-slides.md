<!-- > **最小生成树（MST）**：无向连通图中，边权和最小的生成树。

- 只有**连通图**有生成树；非连通图只有"生成森林"
- MST 总权值唯一，但 MST 本身可能不唯一（存在相同权值的边时）

## 安全边定理（Cut Property）

将图的点集划分为两个不相交的部分 $(S, V-S)$，那么所有连接了 $S$ 和 $V-S$ 的边中权值最小的边必然在 MST 中出现（有多个则只会出现其中之一）。

---

<!-- _class: lead -->




<!-- **Kruskal 和 Prim 的正确性都基于此定理。**

**证明思路**（反证法）：

设跨越割的最小边为 $e$，若存在不包含 $e$ 的 MST $T$：
- $T + e$ 产生一个环
- 环上必存在另一条跨越割的边 $f$（$w(f) \ge w(e)$）
- $T + e - f$ 是另一棵 MST，且包含 $e$ ✓

> 安全边定理 = 贪心选边的理论保证

## 二、Kruskal 算法
### 加边法 · $O(m \log m)$ · 最常用

---

## Kruskal：从小到大加边

**核心思想**：将边按权值排序，贪心加入不形成环的边。

```
边排序: (②,④,1) (①,④,2) (①,②,3) (①,③,5) (④,③,6)
                           ↓
Step 1: 加入 ②-④(1)  → ②④ 连通
Step 2: 加入 ①-④(2)  → ①②④ 连通
Step 3: ①-②(3) 已连通，跳过！
Step 4: 加入 ①-③(5)  → 全部连通，MST完成！
```

**数据结构**：**并查集（DSU）** 维护连通性，`find(u) != find(v)` 判断是否成环。

---

## Kruskal：模板代码

```cpp
struct Edge { int u, v, w; } e[M];
int fa[N];
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }
int kruskal() {
    sort(e + 1, e + m + 1, [](Edge a, Edge b) { return a.w < b.w; });
    for (int i = 1; i <= n; i++) fa[i] = i;
    int ans = 0, cnt = 0;  // cnt: 已选边数
    for (int i = 1; i <= m; i++) {
        int u = find(e[i].u), v = find(e[i].v);
        if (u != v) {           // 不形成环
            fa[u] = v;
            ans += e[i].w;
            if ( ++cnt == n - 1) break;  // MST 只需 n-1 条边
        }
    }
    return (cnt == n - 1) ? ans : -1;  // -1 表示不连通
}
```

---

## Kruskal 正确性直观理解

对每条被选中的边 $e$：

- $e$ 是当时连接两个**不同连通块**的最小边
- $e$ 是连接这两块权值最小的边 → **安全边定理**保证 $e$ 属于某棵 MST

对每条被跳过的边 $e$：

- $e$ 两端已连通 → $e$ 与已选边形成环
- $e$ 是这个环上的最大边（因为更小的边先被加入）
- 删去环上最大边得到更优/等优的生成树 → $e$ 不必加入

> Kruskal = 安全边定理的即时应用

## 三、Prim 算法
### 加点法 · 稠密图首选

---

## Prim：从一点出发逐步扩展

**核心思想**：从一个节点开始，每次选距离当前已选点集**最近**的节点加入。

**类比**：Prim 之于 MST = Dijkstra 之于最短路（都是"加点"，但更新规则不同）

```
当前已选点集 S = {①}
dis[②]=3, dis[③]=5, dis[④]=2  →  加入 ④ (距离最近)
S = {①,④}
dis[②]=min(3, 4)=3, dis[③]=min(5, 6)=5  → 加入 ②
S = {①,④,②}  → 加入 ③
完成！
```

| | Dijkstra | Prim |
|------|:--:|:--:|
| `dis[v]` 含义 | 到**起点**的距离 | 到**当前点集**的距离 |
| 更新公式 | `dis[v] = min(dis[v], dis[u] + w)` | `dis[v] = min(dis[v], w(u,v))` |

---

## 朴素 Prim：$O(n^2)$

```cpp
int prim() {
    memset(dis, 0x3f, sizeof dis);
    dis[1] = 0;
    int res = 0;
    for (int i = 1; i <= n; i++) {
        int u = -1;
        for (int j = 1; j <= n; j++)
            if (!vis[j] && (u == -1 || dis[j] < dis[u]))
                u = j;
        if (dis[u] == INF) return -1;  // 不连通
        vis[u] = true;
        res += dis[u];
        for (int v = 1; v <= n; v++)
            if (!vis[v] && g[u][v] < dis[v])
                dis[v] = g[u][v];
    }
    return res;
}
```

> 稠密图（$m \approx n^2$）时 $O(n^2) < O(m \log m)$，Prim 更优

---

## 堆优化 Prim：$O(m \log n)$

```cpp
int prim() {
    memset(dis, 0x3f, sizeof dis);
    dis[1] = 0;
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;
    pq.push({0, 1});
    int cnt = 0, res = 0;
    while (!pq.empty() && cnt < n) {
        auto [d, u] = pq.top(); pq.pop();
        if (vis[u]) continue;
        vis[u] = true; cnt++; res += d;
        for (auto [v, w] : g[u]) {
            if (!vis[v] && w < dis[v]) {
                dis[v] = w;
                pq.push({w, v});
            }
        }
    }
    return (cnt == n) ? res : -1;
}
```

> ⚠️ 堆优化 Prim 常数比 Kruskal 大，一般只有稠密图/完全图才用

---

## Kruskal vs Prim 选型

| 特性 | Kruskal | Prim（朴素） | Prim（堆优化） |
|------|:--:|:--:|:--:|
| 核心 | 加边 | 加点 | 加点 |
| 数据结构 | 并查集 | 暴力扫描 | 优先队列 |
| 复杂度 | $O(m \log m)$ | $O(n^2)$ | $O(m \log n)$ |
| 稠密图 | 一般 | ✅ **最优** | 一般 |
| 稀疏图 | ✅ **最优** | 差 | 一般 |
| 代码量 | 短 | 短 | 中等 |

**实战口诀：一般情况下用 Kruskal，完全图/稠密图用暴力 Prim。**

## 四、Boruvka 算法
### 多路合并 · 特殊图的利器

---

## Boruvka：每轮选最小出边合并

**核心思想**：初始每个点为一个连通块，每轮对每个连通块找到连向其他块的最小边，将所有这样的边加入 MST，合并连通块。重复直到只剩一个块。

**关键性质**：每轮后连通块数量至少减半，因此最多 $O(\log n)$ 轮。

---
**算法流程**：
1. 初始化并查集，每个点自成一个集合。
2. 循环直到集合数 == 1：
   - 对每个集合，初始化 `best[set] = INF`（记录最小出边）
   - 遍历所有边 $(u,v,w)$：
     - `ru = find(u), rv = find(v)`
     - 若 `ru != rv`：
       - 若 $w < best[ru]$，更新 `best[ru] = (u,v,w)`
       - 若 $w < best[rv]$，更新 `best[rv] = (u,v,w)`
   - 遍历每个集合（通过并查集根节点），若 `best[set]` 存在，则将该边加入 MST（合并两个集合），累加权值。

---

## 正确性证明

每轮中，对于任意一个连通块 $C$，我们选择连接 $C$ 与 $V-C$ 的最小边 $e_C$。由**安全边定理**，$e_C$ 必定属于某棵 MST。

我们同时加入所有 $e_C$（对于所有连通块）。这些边之间不会产生冲突，因为：
- 如果两条边 $e_A$ 和 $e_B$ 连接了不同的块，合并后不会形成环（除非构成环，但环上的边权相等，可任去一条）。
- 实际上，这些边构成一个森林（或有环但可忽略），因此可以安全地同时加入。

因此，每一轮加入的边集都是某个 MST 的子集。最终所有点合并为一个连通块时，得到的正是 MST。

---

## 复杂度分析

- 每轮遍历所有边 $O(m)$，共 $O(\log n)$ 轮，总 $O(m \log n)$。
- 空间 $O(n+m)$。
- 瓶颈在于每轮如何高效地为每个连通块找到最小出边。在通用实现中，扫描所有边即可。

**适用场景**：当 $m$ 很大（如完全图）但能快速查询每个连通块的最小出边时，Boruvka 能避免显式枚举所有边，利用数据结构优化。

---

**与 Kruskal/Prim 对比**：
| 算法 | 复杂度 | 场景 |
|------|------|------|
| Kruskal | $O(m \log m)$ | 一般图，边数适中 |
| Prim（堆） | $O(m \log n)$ | 稀疏图 |
| Boruvka | $O(m \log n)$ | 特殊图（边权可快速查询） |

---


```cpp
int boruvka() {
    for (int i=1; i<=n; ++i) fa[i] = i;
    int ans = 0, cnt = n;  // cnt 为连通块数
    while (cnt > 1) {
        fill(best, best+n+1, -1);
        // 扫描所有边，更新每个连通块的最小出边
        for (int i=0; i<edges.size(); ++i) {
            auto &e = edges[i];
            int ru = find(e.u), rv = find(e.v);
            if (ru == rv) continue;
            if (best[ru] == -1 || e.w < edges[best[ru]].w)
                best[ru] = i;
            if (best[rv] == -1 || e.w < edges[best[rv]].w)
                best[rv] = i;
        }
        // 加入所有最小出边
        for (int i=1; i<=n; ++i) {
            if (best[i] != -1) {
                auto &e = edges[best[i]];
                int ru = find(e.u), rv = find(e.v);
                if (ru != rv) {
                    fa[ru] = rv;
                    ans += e.w;
                    cnt--;
                }
            }
        }
    }
    return ans;
}
```


---

## 典型应用：CF888G Xor-MST

**问题**：给定 $n$ 个点的点权 $a_i$，完全图中边权 $w(i,j) = a_i \oplus a_j$，求 MST。$n \le 2\times 10^5$，$a_i < 2^{30}$。

**分析**：边数 $O(n^2)$ 无法直接建图。Boruvka 中每轮需要为每个连通块找到最小异或出边。

**解法**：
- 用 01-Trie 维护所有点权，支持插入和查询与某个数异或的最小值。
- 每轮中，对于每个连通块，将其所有点从 Trie 中删除（或标记），然后查询该块内所有点的最小异或值（需要排除块内点），即为该块的最小出边。
- 也可以使用可持久化 Trie 或分治优化，但基本思路如此。
- 总复杂度 $O(n \log V \log n)$，其中 $V$ 为值域。

## 五、次小生成树

---

## 非严格次小生成树

**定义**：边权和 **≥** MST 的生成树中，权值最小的。

**核心定理**：次小生成树一定与 MST **只差一条边**。

**算法**：
1. 跑 Kruskal 求出 MST（权值和 $S$），标记树边
2. 枚举每条**非树边** $(u,v,w)$
3. 在 MST 上找 $u \to v$ 路径的**最大边权** $z$
4. $ans = \min(ans,\ S - z + w)$

**维护路径最大边**：倍增 LCA，`mx[u][i]` 记录 $u$ 到 $2^i$ 祖先路径上的最大边权。

---

## 严格次小生成树

**定义**：边权和 **严格 >** MST 的生成树中，权值最小的。

**与上者的区别**：当 $w = z$ 时，替换相同权值的边得到的是非严格解。

**解决方法**：同时维护**最大值**和**严格次大值**。

```cpp
// 倍增表中除了最大值 mx，还要维护严格次大值 smx
int kk[4] = {mx[u][i-1], mx[fa[u][i-1]][i-1],
             smx[u][i-1], smx[fa[u][i-1]][i-1]};
sort(kk, kk + 4);
mx[u][i] = kk[3];           // 最大值
int p = 2;
while (p >= 0 && kk[p] == kk[3]) p--;
smx[u][i] = (p == -1) ? -INF : kk[p];  // 严格次大值
```

**替换时**：若 $w$ = 最大边 → 用次大边替换；否则用最大边替换。

## 六、瓶颈生成树 & 最小瓶颈路

---

## 瓶颈生成树 & 最小瓶颈路

**瓶颈生成树**：最大边权在所有生成树中**最小**的那棵。

> **性质**：MST 一定是瓶颈生成树。（反证法：若 MST 不是，则瓶颈树最大边更小，可替换出更优 MST，矛盾）

**最小瓶颈路**：$x \to y$ 的简单路径中，**最大边权最小**的那条。

> **性质**：$x \to y$ 的最小瓶颈路上的最大边权 = MST 上 $x \to y$ 路径的最大边权。

**应用**：
- 求"最小化路径最大边"的问题，直接在 MST 上处理
- POJ 2395 Out of Hay：求 MST 的最大边

## 七、Kruskal 重构树

---

## 构造方法

在 Kruskal 加边过程中同步建树：

1. 初始 $n$ 个集合，各含一个节点（原图节点，点权为 $0$）
2. 每次合并两集合时：**新建节点**，点权 = 当前边的边权，左/右儿子 = 两集合的根
3. 新节点成为合并后集合的根

```
边权: 1  →  新建节点 A(权1)，儿子: ②,④
边权: 2  →  新建节点 B(权2)，儿子: ①, A
边权: 5  →  新建节点 C(权5)，儿子: ③, B
                 C(5)
                /    \
              ③     B(2)
                    /    \
                   ①    A(1)
                        /    \
                       ②     ④
```


---

## 核心性质
> $n$ 个叶子，$n-1$ 个内部节点，共 $2n-1$ 个节点，恰是一棵二叉树
> 原图中两点所有简单路径上**最大边权的最小值** =
> MST 上两点路径的**最大边权** =
> Kruskal 重构树上两点**LCA 的权值**

**推论**：到点 $x$ 的路径最大边权 $\le val$ 的所有点，恰好是重构树上某节点的**子树中所有叶子**。

**如何找这个节点？**
- 在重构树上从 $x$ 向上倍增跳，找到最浅的满足"权值 $\le val$"的祖先
- 该祖先的子树就是答案

**如果是求最小边权最大值**：按边权**从大到小**排序加边建树。

---

## 经典应用：NOI 2018 归程

**问题**：无向图，每条边有海拔和长度。每天给定起点 $v$ 和水位线 $p$。所有海拔 $\le p$ 的边被淹没（不能走）。求能到达的点中，到 1 号点的最短距离的最小值。

**做法**：

1. **预处理**：跑 Dijkstra，得到每个点到 1 的最短距离 $d[u]$
2. 边按**海拔从大到小**建 Kruskal 重构树（最大生成树）
3. 重构树上，找到 $v$ 的最浅祖先 $u$ 使得 $val[u] > p$（即不会被淹没的最高祖先）
4. 答案 = $u$ 子树中所有叶子的 $d$ 的最小值 → 预处理子树 min

> $O((n+m) \log n + Q \log n)$

## 核心要点回顾

1. **安全边定理**是 Kruskal 和 Prim 正确性的理论基础
2. **Kruskal** = 排序 + 并查集，$O(m \log m)$，是竞赛中最常用的 MST 算法
3. **Prim（朴素）** $O(n^2)$ 在完全图/稠密图中优于 Kruskal
4. **次小生成树** 与 MST 只差一条边；严格次小需维护**严格次大值**
5. **瓶颈生成树**：MST 一定是，但反之不成立
6. **Kruskal 重构树**：LCA 权值 = 最大边权最小值，NOI 2018 归程是经典应用
7. **Boruvka** 在处理边权由公式给出的完全图问题时独树一帜
