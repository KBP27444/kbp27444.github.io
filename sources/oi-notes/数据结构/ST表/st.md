

# ST 表 (Sparse Table)

## 1. 什么是 ST 表？

ST 表 (Sparse Table，稀疏表) 是一种用于解决**可重复贡献问题**的数据结构。最典型的应用就是**静态区间最值查询 (RMQ, Range Minimum/Maximum Query)**。

### 两个关键特征

1. **静态**：不支持修改（如果有修改操作，请出门左转找线段树）。
2. **极速**：预处理时间 `O(N log N)`，单次查询时间绝对的 `O(1)`！

### 限制

只能计算**可重复贡献**：比如求 `max`、`min`、`gcd` 等，一个数字被计算一次还是多次，结果都不变（即 `max(x, x) = x`）。但求"区间和"就不行！

---

## 2. 核心原理：倍增思想与动态规划

ST 表的本质是基于**倍增**的动态规划。

- **状态定义**：设 `st[i][j]` 表示从索引 `i` 开始，长度为 `2^j` 的区间内的最大值。
  - 即区间 `[i, i + 2^j - 1]` 的最大值。

- **初始状态**：`st[i][0] = a[i]`（长度为 `2^0 = 1` 的区间，就是元素本身）。

- **状态转移**：
  把长度为 `2^j` 的区间，劈成两半，每半长度刚好是 `2^(j-1)`。

  `st[i][j] = max(st[i][j-1], st[i + (1 << (j-1))][j-1])`

---

## 3. 为什么查询是 O(1)？

当我们要查询任意区间 `[L, R]` 的最大值时，区间的长度不一定是 2 的整数次幂。怎么用我们存好的 `2^j` 长度的块来拼凑呢？

**核心思路：允许重叠！**

1. 计算区间长度 `len = R - L + 1`。
2. 找到一个最大的 `k`，使得 `2^k <= len`（即 `k = floor(log2(len))`）。
3. 我们用两个长度为 `2^k` 的区间，一左一右强行盖住 `[L, R]`：
   - 第一个区间从 L 开始：涵盖 `[L, L + 2^k - 1]`
   - 第二个区间在 R 结束：涵盖 `[R - 2^k + 1, R]`
4. 答案就是这两个区间最大值的最大值：

   `max(st[L][k], st[R - 2^k + 1][k])`

---

## 4. 具体查询例子

假设原数组（下标从 1 开始）：`A = [5, 2, 8, 3, 7, 1]`

现在想查询区间 `[2, 6]` 的最大值。

### 步骤拆解

- 查询范围 `[2, 6]` 包含元素：`{2, 8, 3, 7, 1}`，区间长度 `len = 5`。
- 求对数：`k = floor(log2(5)) = 2`。对应的区间覆盖长度为 `2^2 = 4`。
- **构造左区间**：从 L = 2 往右长 4 → `[2, 5]`
  - 查表得 `st[2][2] = max(2, 8, 3, 7) = 8`
- **构造右区间**：从 R = 6 往左长 4 → `[3, 6]`
  - 查表得 `st[3][2] = max(8, 3, 7, 1) = 8`

**结论**：虽然 `[2,5]` 和 `[3,6]` 有重叠，但没有关系，只要它们的并集恰好覆盖 `[2,6]` 就行！

## 5. 代码实现

由于内存寻址连续问题，实际实现中我们把表示长度的 `j` 放在第一维。

```cpp
for (int i = 1; i <= n; i++) st[0][i] = a[i];

for (int j = 1; (1 << j) <= n; j++) {
    for (int i = 1; i + (1 << j) - 1 <= n; i++) {
        st[j][i] = max(st[j - 1][i], st[j - 1][i + (1 << (j - 1))]);
    }
}

int query(int L, int R) {
    int k = __lg(R - L + 1);
    return max(st[k][L], st[k][R - (1 << k) + 1]);
}
```

> `__lg` 是一个内置函数，效果是求整型变量 `x` 的 `floor(log2(x))`，复杂度是小常数 `O(1)`，远优于计算浮点数的 `log`。
