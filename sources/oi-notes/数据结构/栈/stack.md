# 栈 (Stack)

## 1. 什么是栈？

栈是一种线性数据结构，它的主要特征可以用四个字概括：

**后进先出 (LIFO - Last In First Out)**

- 规则限制：只允许在集合的同一端进行插入和删除操作。
- 生活中的例子：
  - 叠在一起的一摞盘子（只能从最上面拿，洗好的盘子也放在最上面）
  - 浏览器历史记录的"后退"按钮
  - 文本编辑器的"撤销 (Ctrl+Z)"功能

---

## 2. 核心操作

栈的两个最基本操作是 Push 和 Pop：

- **Push（压栈／入栈）**：将一个新元素放到栈的最顶端。
- **Pop（弹栈／出栈）**：将栈顶的元素移除。
- **Top（获取栈顶）**：查看当前栈顶的元素是谁（不移除）。
- **Empty（判空）**：检查栈内是否还有元素。

> 注意：栈底（最早进入的元素）是无法直接访问的，必须把上面的元素都 Pop 掉才能碰到它。

---

## 3. 举例说明：Push 与 Pop

假设我们有一个空栈，依次执行以下操作：

1. `Push(10)`：栈变为 `[10]`（10 是栈顶）
2. `Push(20)`：栈变为 `[10, 20]`（20 是栈顶）
3. `Push(30)`：栈变为 `[10, 20, 30]`（30 是栈顶）
4. `Pop()`：移除栈顶 30，栈变为 `[10, 20]`（20 重新成为栈顶）
5. `Push(40)`：栈变为 `[10, 20, 40]`（40 是栈顶）

当前栈的状态（从底到顶）：`10 -> 20 -> 40`（Top）

---

## 4. 数组模拟栈

```cpp
int stk[MAX], top = 0;

// 入栈 (Push)
void push(int x) {
    stk[++top] = x;
}

// 出栈 (Pop)
void pop() {
    top--;
}

// 获取栈顶元素 (Top)
int get_top() {
    return stk[top];
}

// 判空 (Empty)
bool is_empty() {
    return top == 0;
}
```

## 5. std::stack

STL 为我们准备了 `std::stack`，开箱即用。

```cpp
stack<int> stk;

stk.push(x);

stk.pop();

// 获取栈顶元素 (Top)

// 判空 (Empty)
if (stk.empty()) {
    // do something
}
```

## 6. 经典应用：合法括号序列匹配

### 问题描述

给定一个只包含 `(`、`)`、`{`、`}`、`[`、`]` 的字符串，判断字符串是否是一个有效的括号序列。

有效字符串需满足：
1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。

### 示例

- `()[]{}` → 合法
- `([)]` → 不合法
- `{{}}` → 合法

### 为什么用栈？

当我们遇到一个"右括号"时，它必须和**最近出现**且还没有被匹配的"左括号"配对。这完美契合了栈的**后进先出 (LIFO)** 特性。

### 算法步骤

1. 从左到右遍历字符串。
2. 遇到左括号：直接压入栈中（Push）。
3. 遇到右括号：
   - 如果栈为空，说明没有对应的左括号，非法。
   - 如果栈顶元素与该右括号类型匹配，则弹出栈顶（Pop）。
   - 如果类型不匹配，非法。
4. 遍历结束后，如果栈为空，说明全部匹配成功；否则非法。

```cpp
bool isValid(string s) {
    stack<char> stk;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            stk.push(c);
        } else {
            if (stk.empty()) return false;
            char t = stk.top();
            if ((c == ')' && t == '(') ||
                (c == ']' && t == '[') ||
                (c == '}' && t == '{')) {
                stk.pop();
            } else {
                return false;
            }
        }
    }
    return stk.empty();
}
```

## 7. 拓展：极值栈

极值栈在普通栈的基础上多了一个查询当前栈内最值的功能。其实现很简单，只需在记录每个元素时记录一下当前最值即可。

```cpp
stack<pair<int, int>> stk;

// 入栈 (Push)
stk.push({x, max(x, stk.top().second)});

// 获取栈顶元素 (Top)
int t1 = stk.top().first;

// 获取栈内最值
int t2 = stk.top().second;
```

实际上不一定是最值，维护的东西只需要是个满足**结合律**的二元运算即可，如 `gcd`、异或甚至矩阵乘法、字符串哈希均可采用这种方法。我们把满足这种性质的东西叫做**半群**。

---

## 8. 拓展：单调栈

**核心功能**：寻找数组中每一个元素左侧/右侧的**第一个比它大/小**的元素。

**规则**（以寻找右侧第一个比它大的元素为例，维护单调递减栈）：

1. 从左到右遍历数组。
2. 每次新元素准备入栈时，把它和栈顶比较：
   - 如果新元素大于栈顶元素，说明新元素就是栈顶元素右侧第一个比它大的。此时将栈顶元素弹出，记录答案。
   - 重复上述弹出过程，直到栈顶元素大于新元素，或者栈为空，然后新元素入栈。

# 队列 (Queue)

## 1. 什么是队列？

队列同样是一种线性数据结构，它的主要特征恰好与栈相反：

**先进先出 (FIFO - First In First Out)**

- 规则限制：只能在**队尾 (Tail/Rear)** 插入元素，在**队首 (Head/Front)** 删除元素。
- 生活中的例子：
  - 食堂打饭排队（先来的人先打到饭离开）
  - 打印机的任务队列

---

## 2. 核心操作

队列的核心操作也围绕着进出展开，但发生在一头一尾：

- **Push（入队）**：将一个新元素加入到队伍的末尾。
- **Pop（出队）**：将队伍最前面的元素移除。
- **Front（获取队首）**：查看当前排在队伍最前面的元素是谁。
- **Back（获取队尾）**：查看当前排在队伍最后面的元素是谁。
- **Empty（判空）**：检查队伍是否已经没人了。

---

## 3. 举例说明：入队与出队

假设我们有一个空队列，左边是"队首"（出口），右边是"队尾"（入口）：

1. `Push(10)`：队列变为 `[10]`（10 既是队首也是队尾）
2. `Push(20)`：队列变为 `[10, 20]`（10 是队首，20 是队尾）
3. `Push(30)`：队列变为 `[10, 20, 30]`
4. `Pop()`：移除队首 10，队列变为 `[20, 30]`（20 成为新队首）
5. `Push(40)`：队列变为 `[20, 30, 40]`

当前队列状态：队首 Front → `20, 30, 40` ← Back 队尾

---

## 4. 数组模拟队列

```cpp
int q[MAXN], head = 1, tail = 0;

// 入队 (Push)
void push(int x) {
    q[++tail] = x;
}

// 出队 (Pop)
void pop() {
    if (head <= tail) head++;
}

// 获取队首元素 (Front)
int front() {
    return q[head];
}

// 判空 (Empty)
bool empty() {
    return head > tail;
}
```


## 6. 双端队列 (deque)

实际上 STL 还有个双端队列，双端队列可以同时访问队首、队尾，把队首、队尾的元素弹出。

可以发现，栈和队列都可以用双端队列来模拟，实际上，STL 就是这么做的。

```cpp
// 入队 (Push)
q.push_front(x);
q.push_back(y);

// 出队 (Pop)
q.pop_front();
q.pop_back();

// 获取队首队尾元素 (Front / Back)
int t1 = q.front(), t2 = q.back();
```

> **注意**：由于 `stack` 和 `queue` 都是 `deque` 实现的，并且由于实现特殊，一个空的 `deque` 都会占据大量内存，更别说在里面插入几个元素了。
>
> 所以，在使用大量 `deque` 类容器时（包括 `stack` 和 `queue`）需谨慎内存。
>
> 一般来说，如果只需要 `stack` 的功能时，往往会采用 `vector` 来代替。否则，如果真的不得不开这么多容器，建议使用 `list`。

## 7. 单调队列

**核心功能**：解决滑动窗口最值问题 (Sliding Window Maximum/Minimum)。

**问题背景**：给定一个数组，和一个大小为 `K` 的窗口，窗口从左向右滑动，求每次窗口内的最大值。

**单调队列的结构**：双端队列 (Deque)。

- **队尾 (Tail)**：负责淘汰比新元素弱的元素（维持单调性）。
- **队首 (Head)**：负责输出当前窗口的最大值，并淘汰"过期"的元素（生命周期结束）。

### 核心两步走

1. **去尾（保持单调）**：新元素加入时，从队尾开始把所有 `<=` 新元素的数统统删除。
2. **掐头（清理过期）**：检查队首的元素是不是已经不在滑动窗口范围 `K` 内了，如果过期了，队首也要强制弹出。

> **关键提醒**：和单调栈一样，队列里存放的**必须是下标**！只有存下标，你才能在"掐头"时判断元素是否过期！

```cpp
deque<int> q;
for (int i = 1; i <= n; i++) {
    while (!q.empty() && a[i] >= a[q.back()]) q.pop_back();
    q.push_back(i);
    if (q.front() <= i - k) q.pop_front();
    if (i >= k) {
        cout << a[q.front()] << " ";
    }
}
```

## 8. 优先队列 (Priority Queue)

不同于队列或者栈，优先队列不是线性数据结构，可以认为其是一种集合类型的数据结构。

- 规则限制：优先级和插入元素顺序无关，只能删除或访问**最大**的元素。
- 生活中的例子：
  - 医院的急诊分诊（危重病人优先）
  - 操作系统的进程调度（高优先级进程先执行）

---

## 9. std::priority_queue

STL 为我们准备了 `std::priority_queue`，开箱即用。

```cpp
priority_queue<int> q;

// 入队 (Push)
q.push(x);

// 出队 (Pop)
q.pop();

// 获取队首元素 (Top)
int t = q.top();

// 判空 (Empty)
if (q.empty()) {
    // do something
}
```

> 注意：`priority_queue` 的 `top()` 是最大的元素。如果要让其是最小的元素，可以将每个元素取相反数，或者使用 `priority_queue<int, vector<int>, greater<int>>`。

## 10. 对顶堆

对顶堆是一种利用两个堆维护动态数据集的**中位数**（或其他分位数）的技巧。

- **大根堆 (max-heap)**：存储数据中较小的一半，堆顶为这部分的最大值。
- **小根堆 (min-heap)**：存储数据中较大的一半，堆顶为这部分的最小值。

### 核心性质

保持大根堆的大小等于小根堆的大小，或者大根堆比小根堆多 1 个元素。此时，大根堆的堆顶即为当前数据集的中位数（若总数为奇数）或两个堆顶的平均值（若总数为偶数）。

### 插入流程

1. 新元素 `x` 入堆：
   - 若大根堆为空或 `x <=` 大根堆堆顶，则插入大根堆；
   - 否则插入小根堆。
2. 平衡调整：
   - 若大根堆大小 < 小根堆大小，将小根堆堆顶移到大根堆；
   - 若大根堆大小 > 小根堆大小 + 1，将大根堆堆顶移到小根堆。

### 查询中位数

- 若总数为奇数，返回大根堆堆顶；
- 若总数为偶数，返回 (大根堆堆顶 + 小根堆堆顶) / 2。

```cpp
priority_queue<int> q1;                            // 较小的一半
priority_queue<int, vector<int>, greater<int>> q2; // 较大的一半

void addNum(int num) {
    if (q1.empty() || num <= q1.top()) q1.push(num);
    else q2.push(num);

    if (q1.size() < q2.size()) {
        q1.push(q2.top());
        q2.pop();
    } else if (q1.size() > q2.size() + 1) {
        q2.push(q1.top());
        q1.pop();
    }
}

double findMedian() {
    if (q1.size() > q2.size())
        return q1.top();
    return (q1.top() + q2.top()) / 2.0;
}
```
