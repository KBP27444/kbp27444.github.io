

# 普及数据结构：栈、队列、链表、向量

2026.08.02 LPF

---

## 1 总览

### 用容器组织信息

数据结构解决的不是"把数存起来"，而是让常用操作足够快。

这节内容聚焦四个最常见的线性结构：

- **向量**：连续存放，按下标访问。
- **栈**：后进先出，只看一端。
- **队列**：先进先出，从一端进另一端出。
- **链表**：用指针连接，插入删除更灵活。

先看题目需要哪些操作，再决定用什么容器。

---

### 学习路线

| 结构 | 最擅长的操作 | 常见模型 |
|---|---|---|
| 向量 | 下标访问、尾部追加、排序去重 | 数组模拟、离散化、记录序列 |
| 栈 | 只访问最后加入的元素 | 括号匹配、表达式、单调栈 |
| 队列 | 按进入顺序依次处理 | 模拟、BFS、滑动窗口 |
| 链表 | 已知位置附近插入删除 | 队列安排、约瑟夫、邻接表 |

---

### 先把操作翻译清楚

读到一个模拟或数据结构题，可以先问：

- 是否需要随机访问第 `i` 个元素？
- 是否只会在末尾加入或删除？
- 是否总是处理最早加入的元素？
- 是否总是处理最后加入的元素？
- 是否经常在中间插入或删除？

这五个问题基本能区分向量、栈、队列和链表。

---

### 复杂度小地图

| 操作 | vector | stack | queue |
|---|---|---|---|
| 访问首尾 | `O(1)` | `O(1)` 看栈顶 | `O(1)` 看队首 |
| 访问第 i 个 | `O(1)` | 不支持 | 不支持 |
| 尾部加入 | `O(1)` 均摊 | `O(1)` | `O(1)` |
| 中间删除 | `O(n)` | 不支持 | 不支持 |

链表的中间插入删除在"已经知道位置"时是 `O(1)`，但查找位置通常仍要 `O(n)`。

---

### STL 的安全习惯

常见容器函数很多，但入门阶段先记稳定用法：

- `empty()` 判断是否为空。
- `size()` 返回元素个数。
- `push_back()` / `push()` 加入元素。
- `pop_back()` / `pop()` 删除元素。
- `front()` / `back()` / `top()` 访问端点。

访问端点前先判断是否为空，这是最重要的安全习惯。

---

### 容器与"降维"

很多题看起来要维护很多信息，本质上只是把当前必要信息留在容器里。

| 场景 | 压缩后的信息 | 常用结构 |
|---|---|---|
| 值域太大 | 只保留出现过的值的排名 | vector |
| 括号或路径回退 | 只保留还没匹配的对象 | stack |
| 按时间依次过期 | 只保留当前窗口里的对象 | queue |
| 候选会被淘汰 | 只保留仍可能最优的候选 | 单调栈 / 队列 |

## 2 向量 vector

### vector：会自动变长的数组

vector 可以理解成"长度可变的数组"。

它的特点：

- 元素连续存放。
- 支持 `a[i]` 直接访问。
- 末尾加入很快。
- 中间插入删除会整体移动后面的元素。

适合保存序列、答案、坐标、图的邻接表。

---

### 什么时候选 vector

优先考虑 vector 的场景：

- 数据规模不固定，读入时才知道数量。
- 需要排序、去重、二分查找。
- 需要用下标遍历。
- 需要保存每个点的邻接点列表。

不适合：

- 频繁在开头或中间插入删除。
- 只关心队首出队。

---

### vector 常用操作

| 写法 | 作用 | 复杂度 |
|---|---|---|
| `a.push_back(x)` | 在末尾加入 x | `O(1)` 均摊 |
| `a.pop_back()` | 删除最后一个元素 | `O(1)` |
| `a[i]` | 访问第 i 个元素 | `O(1)` |
| `a.size()` | 元素个数 | `O(1)` |
| `sort(a.begin(), a.end())` | 排序 | `O(n log n)` |

`pop_back()` 只负责删除，不会返回被删掉的值。

---

### 模板：读入、遍历、求和

```cpp
int n;
cin >> n;

vector<long long> a(n);
for (int i = 0; i < n; i++) cin >> a[i];

long long sum = 0;
for (long long x : a) sum += x;

cout << sum << '\n';
```

下标从 0 开始，最后一个元素是 `a[n - 1]`。

---

### 模板：动态追加

```cpp
vector<int> a;

for (int i = 1; i <= n; i++) {
    int x;
    cin >> x;
    if (x > 0) a.push_back(x);
}

cout << a.size() << '\n';
```

---

### 排序与去重

```cpp
sort(a.begin(), a.end());
a.erase(unique(a.begin(), a.end()), a.end());
```

这一套常用于：

- 统计不同数字个数。
- 把大值域压成小下标。
- 为二分查找准备有序序列。

`unique` 只把相邻重复元素挪到后面，所以前面必须先排序。

---

### 离散化：把大坐标压成小编号

当数值很大，但出现次数不多时，可以只关心它在所有出现值中的排名。

例如原始值：`1000000000, 7, 7, 35`

排序去重后：`7, 35, 1000000000`

于是可以映射成：
- `7 -> 1`
- `35 -> 2`
- `1000000000 -> 3`

---

### 模板：离散化

```cpp
vector<int> xs = a;
sort(xs.begin(), xs.end());
xs.erase(unique(xs.begin(), xs.end()), xs.end());

for (int &x : a) {
    x = lower_bound(xs.begin(), xs.end(), x) - xs.begin() + 1;
}
```

离散化之后，值域从"很大"变成"不同元素个数"。这就是降维技巧里很常见的"压缩一维大小"。

---

### 二分查找

有序 vector 可以用二分查找：

```cpp
sort(a.begin(), a.end());

auto it = lower_bound(a.begin(), a.end(), x);
if (it != a.end() && *it == x) {
    cout << "found\n";
}
```

`lower_bound` 返回第一个大于等于 `x` 的位置。

---

### 删除元素的代价

vector 删除中间元素时，后面的元素会整体前移。

```cpp
a.erase(a.begin() + pos);
```

这一步是 `O(n)`。

如果题目有很多中间删除，常需要换思路：

- 用链表维护相邻关系。
- 用标记数组表示"已经删除"。
- 先离线处理，再统一过滤。

### vector 小结

vector 是最常用的基础容器。

记住三个判断：

- 要随机访问：用 vector。
- 要排序去重：用 vector。
- 中间频繁插入删除：先别急着用 vector。

它经常和二分、离散化、邻接表一起出现。

## 3 栈 stack

### stack：后进先出

栈只允许访问最后加入的元素。

这叫后进先出：

- 新元素从栈顶进入。
- 删除时也从栈顶删除。
- 只能看栈顶，不能看中间。

现实类比：一摞书，最后放上去的最先拿走。

---

### 栈适合处理"最近的未完成事件"

栈常见于：

- 括号匹配：最近的左括号等待匹配。
- 表达式计算：最近的操作数等待合并。
- 路径回退：走不通就退回上一步。
- 单调栈：新元素淘汰一批旧候选。

这些场景都只关心"最后留下来的那个对象"。

---

### stack 常用操作

| 写法 | 作用 | 复杂度 |
|---|---|---|
| `s.push(x)` | 把 x 放到栈顶 | `O(1)` |
| `s.pop()` | 删除栈顶元素 | `O(1)` |
| `s.top()` | 访问栈顶元素 | `O(1)` |
| `s.empty()` | 判断是否为空 | `O(1)` |
| `s.size()` | 元素个数 | `O(1)` |

`top()` 和 `pop()` 前都要确认栈非空。

---

### 模板：基础栈

```cpp
stack<int> s;

s.push(3);
s.push(5);

cout << s.top() << '\n';  // 5

s.pop();

cout << s.top() << '\n';  // 3
```

栈的访问顺序与加入顺序相反。

---

### 括号匹配

遇到左括号就入栈。

遇到右括号：

- 如果栈空，说明没有左括号可匹配。
- 否则弹出一个左括号。

最后栈为空，所有左括号都匹配成功。

这个模型只需要保存"还没被匹配的左括号"。

---

### 模板：括号匹配

```cpp
bool ok = true;
stack<char> s;

for (char c : str) {
    if (c == '(') s.push(c);
    else if (c == ')') {
        if (s.empty()) ok = false;
        else s.pop();
    }
}

if (!s.empty()) ok = false;
```

只含一种括号时，栈里甚至可以只存数量。

---

### 多种括号

多种括号需要检查类型是否对应。

```cpp
bool match(char l, char r) {
    return (l == '(' && r == ')') ||
           (l == '[' && r == ']') ||
           (l == '{' && r == '}');
}
```

右括号到来时，必须与最近的未匹配左括号配对。这正是栈的后进先出性质。

---

### 表达式：先保存，后合并

后缀表达式中，数字入栈，运算符取出两个数字计算。

例如：`3 4 + 5 *`

过程：

- `3, 4` 入栈。
- `+` 取出 `3, 4` 得到 `7`。
- `5` 入栈。
- `*` 取出 `7, 5` 得到 `35`。

---

### 模板：后缀表达式核心

```cpp
stack<long long> s;

if (is_number(token)) s.push(value);
else {
    long long b = s.top(); s.pop();
    long long a = s.top(); s.pop();

    if (token == "+") s.push(a + b);
    if (token == "-") s.push(a - b);
    if (token == "*") s.push(a * b);
}
```

注意先弹出的是右操作数 `b`。

---

### 验证出栈序列

给定入栈顺序和目标出栈顺序，可以模拟：

- 按入栈顺序不断 `push`。
- 只要栈顶等于当前目标，就 `pop`。
- 最后目标全部匹配则可行。

这个过程不需要枚举所有操作，只需要贪心模拟。

---

### 模板：验证出栈序列

```cpp
stack<int> s;
int j = 0;

for (int x : in) {
    s.push(x);
    while (!s.empty() && j < n && s.top() == out[j]) {
        s.pop();
        j++;
    }
}

cout << (j == n ? "Yes" : "No") << '\n';
```

---

### 单调栈：弹掉没用的候选

单调栈维护一个有序的候选集合。

以"找左边第一个更大元素"为例：

- 栈里保存还可能成为答案的位置。
- 当前值更大时，比它小的栈顶不可能再作为后面元素的更大值。
- 不可能再用的元素被弹出。

每个元素只会被压入一次、弹出一次，所以总复杂度是 `O(n)`。

---

### 模板：左侧第一个更大值

```cpp
vector<int> ans(n, -1);
stack<int> st;  // 存下标

for (int i = 0; i < n; i++) {
    while (!st.empty() && a[st.top()] <= a[i]) st.pop();
    if (!st.empty()) ans[i] = st.top();
    st.push(i);
}
```

把 `<=` 改成 `<`，会改变"相等元素"如何处理。

### 栈小结

栈的关键词是"最近"。

常见写法：

- 最近的左括号。
- 最近的操作数。
- 最近没有被淘汰的候选。
- 最近走过的路径点。

当题目只允许从一端回退，栈通常是第一选择。

## 4 队列 queue

### queue：先进先出

队列从队尾加入，从队首删除。

这叫先进先出：

- 先来的先处理。
- 后来的排在后面。
- 每个元素按时间顺序离开。

现实类比：排队买票，先排的人先办理。

---

### 队列适合处理"按时间推进"

常见场景：

- 普通模拟：事件按到达顺序处理。
- BFS：按距离从小到大扩展。
- 滑动窗口：过期元素从队首离开。
- 多源扩散：多个起点一起排队。

队列把"先后顺序"固定下来。

---

### queue 常用操作

| 写法 | 作用 | 复杂度 |
|---|---|---|
| `q.push(x)` | 把 x 放到队尾 | `O(1)` |
| `q.pop()` | 删除队首元素 | `O(1)` |
| `q.front()` | 访问队首元素 | `O(1)` |
| `q.back()` | 访问队尾元素 | `O(1)` |
| `q.empty()` | 判断是否为空 | `O(1)` |

`pop()` 只删除，不返回值。

---

### 模板：普通队列

```cpp
queue<int> q;

q.push(10);
q.push(20);

while (!q.empty()) {
    int x = q.front();
    q.pop();
    cout << x << '\n';
}
```

输出顺序是 `10, 20`。

---

### 数组模拟队列

当需要更快、更可控时，可以用数组模拟。

```cpp
int q[N], head = 0, tail = 0;

q[tail++] = x;          // 入队
int y = q[head++];      // 出队

bool empty = (head == tail);
```

队列中的元素位于 `[head, tail)`。

---

### 循环队列

如果队列空间固定，可以让下标循环。

```cpp
tail = (tail + 1) % M;
head = (head + 1) % M;
```

循环队列常用于：

- 固定大小缓存。
- 不希望数组下标一直变大。
- 手写高性能队列。

普及阶段更多时候直接使用 `queue` 或数组队列即可。

---

### BFS：队列的核心应用

BFS 从起点开始，一层一层向外扩展。

队列保证：

- 距离小的点先出队。
- 第一次到达某个点时，距离就是最短距离。
- 每条边最多被检查有限次数。

适合求无权图、网格图中的最短步数。

---

### 模板：图上 BFS

```cpp
queue<int> q;
vector<int> dist(n + 1, -1);

dist[s] = 0;
q.push(s);

while (!q.empty()) {
    int u = q.front();
    q.pop();

    for (int v : g[u]) {
        if (dist[v] == -1) {
            dist[v] = dist[u] + 1;
            q.push(v);
        }
    }
}
```

`dist[v] == -1` 同时表示"还没访问过"。

---

### 网格 BFS

网格题常把一个格子看成一个点。

```cpp
int dx[4] = {1, -1, 0, 0};
int dy[4] = {0, 0, 1, -1};

for (int k = 0; k < 4; k++) {
    int nx = x + dx[k], ny = y + dy[k];
    if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
    if (blocked[nx][ny] || dist[nx][ny] != -1) continue;
    dist[nx][ny] = dist[x][y] + 1;
    q.push({nx, ny});
}
```

边界、障碍、是否访问过，三项都要检查。

---

### deque：两端都能操作

deque 支持两端加入和删除。

| 写法 | 作用 | 复杂度 |
|---|---|---|
| `dq.push_front(x)` | 头部加入 | `O(1)` |
| `dq.push_back(x)` | 尾部加入 | `O(1)` |
| `dq.pop_front()` | 删除头部 | `O(1)` |
| `dq.pop_back()` | 删除尾部 | `O(1)` |

单调队列通常用 `deque` 实现。

---

### 单调队列：窗口最值

滑动窗口中，每次窗口右端右移，左端也可能右移。

单调队列维护仍在窗口内、且可能成为最值的下标：

- 队首是当前窗口答案。
- 队尾弹掉不可能更优的旧元素。
- 队首过期时弹出。

它和单调栈一样，每个元素最多进出一次。

---

### 模板：滑动窗口最大值

```cpp
deque<int> q;
for (int i = 1; i <= n; i++) {
    while (!q.empty() && a[i] >= a[q.back()]) q.pop_back();
    q.push_back(i);
    if (q.front() <= i - k) q.pop_front();
    if (i >= k) {
        cout << a[q.front()] << " ";
    }
}
```

### 队列小结

队列的关键词是"最早"。

常见写法：

- 最早加入的任务先处理。
- 最早过期的元素先删除。
- BFS 中最早到达的一层先扩展。

当顺序由时间决定，队列通常很自然。

## 5 链表 linked list

### 链表：用指针连接元素

数组和 vector 依靠连续下标找元素。

链表依靠"下一个是谁"找元素。

每个节点通常包含：

- 当前值。
- 指向下一个节点的位置。
- 双向链表还会记录上一个节点。

链表更重视相邻关系，而不是第几个元素。

---

### 链表的优势与代价

优势：

- 已知位置后，插入删除附近节点很快。
- 不需要整体移动后面的元素。
- 适合维护动态相邻关系。

代价：

- 不能 `O(1)` 访问第 `i` 个元素。
- 查找某个位置可能要一路走过去。
- 指针写错容易断链。

---

### 单链表插入

要在节点 `p` 后插入新节点 `x`：

```
nxt[x] = nxt[p];
nxt[p] = x;
```

顺序不能反。

先让新节点接上原来的后继，再让 `p` 指向新节点。这样原来的后继不会丢失。

---

### 单链表删除

要删除节点 `p` 后面的节点：

```cpp
int x = nxt[p];
nxt[p] = nxt[x];
```

如果需要回收节点，可以把 `x` 放进空闲列表。普通竞赛模拟中，很多时候只要断开关系即可。

---

### 数组模拟链表

竞赛中经常用数组代替真实指针：

```cpp
int val[N], nxt[N], tot = 0;

int new_node(int x) {
    val[++tot] = x;
    nxt[tot] = 0;
    return tot;
}
```

节点编号就是"指针"。

这种写法稳定、好调试，也不容易出现内存问题。

---

### 双向链表

双向链表同时记录前驱和后继。

```cpp
int pre[N], nxt[N];

void link(int a, int b) {
    nxt[a] = b;
    pre[b] = a;
}
```

删除节点 `x`：

```cpp
link(pre[x], nxt[x]);
```

双向链表适合需要向左、向右都能移动的场景。

---

### 哨兵节点

哨兵节点可以减少边界判断。常见设计：

- `0` 表示头哨兵。
- `n + 1` 表示尾哨兵。
- 真正元素夹在两个哨兵之间。

删除第一个、最后一个元素时，也能使用同一套代码。边界越统一，模拟越不容易写错。

---

### 链表与邻接表

图的邻接表也可以看作链表。

```cpp
int head[N], to[M], nxt[M], tot;

void add_edge(int u, int v) {
    to[++tot] = v;
    nxt[tot] = head[u];
    head[u] = tot;
}
```

`head[u]` 是第一条边，`nxt[i]` 指向下一条边。这是"头插法"的链表。

---

### 链表与约瑟夫问题

约瑟夫问题可以用循环链表理解：

- 所有人围成一个环。
- 每次数到目标位置。
- 删除该位置。
- 从下一个位置继续。

规模较小时可以直接模拟；规模较大时要用数学递推。链表模型让"删除后接上两边"很直观。

### 链表小结

链表的关键词是"相邻关系"。

常见写法：

- `nxt[x]` 表示右边是谁。
- `pre[x]` 表示左边是谁。
- 插入时先接新节点，再改旧连接。
- 删除时把左右两侧直接连起来。

写链表时最重要的是画清楚指向关系。

## 6 综合选择

### 四种结构如何选择

| 需求 | 优先选择 | 原因 |
|---|---|---|
| 按下标访问 | vector | 连续存放，访问快 |
| 最近加入先处理 | stack | 后进先出 |
| 最早加入先处理 | queue | 先进先出 |
| 两端都要操作 | deque | 头尾都是 `O(1)` |
| 已知位置插入删除 | 链表 | 不移动整段元素 |

如果一个结构不直接支持目标操作，硬做通常会变慢。

---

### 组合使用很常见

很多题不会只出现一个容器。

| 组合 | 作用 | 例子 |
|---|---|---|
| vector + sort | 整理序列 | 统计数字、离散化 |
| queue + visited | 按层扩展 | BFS 最短路 |
| stack + vector | 保存路径和答案 | 括号、DFS |
| deque + 下标 | 维护窗口候选 | 滑动窗口最值 |
| 链表 + 标记 | 删除后避免重复处理 | 队列安排 |

重点是让每个容器只做自己擅长的事。

---

### 常见错误清单

- 空栈调用 `top()`。
- 空队列调用 `front()`。
- `pop()` 后又使用旧的端点值。
- vector 下标从 1 写到 n，访问越界。
- `erase` 在循环中导致迭代器失效。
- 链表插入时改指针顺序错误。
- 单调队列忘记删除过期下标。

调试时先检查这些位置。

---

### 从暴力到容器

很多普及题可以按三步推进：

1. 先写出最直接的模拟。
2. 找到反复变慢的操作。
3. 用合适容器把这个操作降到 `O(1)` 或 `O(log n)`。

例如：

- 每次找最近未匹配括号 → 栈。
- 每次删除最早过期记录 → 队列。
- 每次查询窗口最大值 → 单调队列。

---

### 小型模板总表

| 结构 | 加入 | 取出 / 查看 |
|---|---|---|
| vector | `push_back(x)` | `back()`, `a[i]`, `pop_back()` |
| stack | `push(x)` | `top()`, `pop()` |
| queue | `push(x)` | `front()`, `pop()` |
| deque | `push_front/back(x)` | `front()`, `back()`, `pop_front/back()` |
| 链表 | 修改 pre/nxt | 沿 nxt 或 pre 移动 |

把函数名记熟，模拟题会清爽很多。

---

### 训练路线

可以按这样的顺序巩固：

- vector：读入、排序、去重、下标模拟。
- stack：括号匹配、后缀表达式、出栈序列。
- queue：普通模拟、BFS、时间窗口。
- deque：滑动窗口最大值、最小值。
- 链表：队列安排、循环删除、邻接表。

每一类先写模板，再做一两道完整题。

---

### 最后一张图

| 结构 | 一句话记法 | 最常见用途 |
|---|---|---|
| vector | 可变长数组 | 存序列、排序、离散化 |
| stack | 最后来的先走 | 括号、表达式、单调栈 |
| queue | 先来的先走 | 模拟、BFS、过期删除 |
| deque | 两边都能走 | 单调队列、双端模拟 |
| 链表 | 节点互相指向 | 插入删除、邻接表 |

容器本身不难，难点在于把题目里的操作翻译成这些结构能做的动作。
